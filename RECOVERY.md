# Калькулятор 1.1.0 (3)

## Установка через ESign

Импортируйте IPA, подпишите своим сертификатом и установите. Название внутри
сборки — «Калькулятор», bundle identifier — `com.securevault.app`.
Для обновления сохраните идентификатор установленного приложения.

## Новый вход

При обнаружении старой постоянной блокировки приложение завершает очистку
и открывает создание личного кода. Постоянная блокировка больше не создаётся:
Action Button «Стереть данные и сбросить вход» возвращает к первоначальной настройке.

Введите новый код дважды и нажмите «Создать и открыть хранилище».
Хранилище откроется сразу. Следующий вход через калькулятор: AC → код → =.

Если старый код сохранился, при первом запуске версии 1.1.0 будет экран входа.
Можно ввести его или выбрать «Создать пустое хранилище» с подтверждением удаления.
Этот экран также доступен из правого верхнего меню калькулятора → «Хранилище».
Сброс доступен независимо от наличия старых флагов блокировки.

Сброс удаляет оставшиеся фото, заметки, ключ и коды. Удалённые данные не восстанавливаются.
Ошибка чтения/сохранения кода или очистки показывается на экране, а не скрывается
за неработающим калькулятором. При ошибке очистки нажмите «Повторить очистку».

## Проверки

GitHub Actions запускает тесты хранения, удаления, редактора и два UI-сценария:
старая блокировка → новый код → хранилище → калькулятор → повторный вход после
перезапуска; сохранённый старый код → доступный сброс → новое хранилище.
После тестов сохраняется снимок экрана симулятора Calculator-preview и IPA.
Проверка подписанной через ESign сборки на физическом iPhone выполняется отдельно.
