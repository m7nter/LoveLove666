# Калькулятор 1.1.1 (4)

Импортируйте IPA в ESign, подпишите своим сертификатом и установите поверх прежней версии
с прежним идентификатором `com.securevault.app`, чтобы сохранить данные.

Обычный запуск показывает только калькулятор. В меню режимов нет хранилища и версии.
Вход по существующему коду: AC → личный код → =.

Для первой настройки или восстановления **удерживайте число результата 3 секунды**.
Этот жест открывает скрытый экран доступа. Введите существующий код или создайте новый,
если кода ещё нет. Настройку можно закрыть кнопкой «Калькулятор».

Если код потерян, «Создать пустое хранилище» удаляет старые фото, заметки, настройки,
коды и ключ после отдельного подтверждения. После очистки снова удерживайте результат
3 секунды и создайте новый код. Удалённые данные не восстановятся.

Старая постоянная блокировка завершается полным сбросом. Действие Action Button
«Стереть данные и сбросить вход» больше не создаёт вечного запрета. При ошибке очистки
скрытый экран показывает ошибку и «Повторить очистку». Обычный калькулятор остаётся доступным.

GitHub Actions проверяет сценарии старой блокировки, нового кода, повторного входа,
перезапуска, сброса и отсутствия хранилища в обычном меню. Звук, тактильные ощущения
и подписанная сборка ESign на физическом iPhone проверяются отдельно.
