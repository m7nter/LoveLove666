# LoveLove666 — восстановление после отключения хранилища

Версия 1.0.1, сборка 2. Основа: «ласт версия лавшоп.zip».

После установки этой версии поверх заблокированного приложения:

1. Откройте меню с иконкой калькулятора в правом верхнем углу.
2. Выберите «Создать пустое хранилище».
3. Подтвердите «Создать заново». Остатки данных, старые пароли и ключ будут удалены.
4. Дождитесь окончания очистки и задайте новый личный код.
5. Введите новый код в калькуляторе и нажмите `=`.

Это создаёт пустое хранилище. Удалённые фотографии и заметки не восстанавливаются.
Если удаление завершилось ошибкой, приложение остаётся закрытым для доступа к
хранилищу. Исправьте причину ошибки и нажмите «Повторить удаление».

При полноценной новой установке создание личного кода доступно при первом
запуске. Если сохранился ранее заданный код и блокировки нет, используйте его.

## Сборка

Исходники должны находиться в корне репозитория. Workflow расположен в
`.github/workflows/main.yml`, запускается при push в main/master или вручную
через Actions. Используется установленный по умолчанию Xcode на macos-26.
Сначала запускаются XCTest, затем собирается приложение и архивируется IPA.
Артефакт `LoveLove666-IPA` содержит неподписанный `SecureVault.ipa`.
Для установки на iPhone IPA нужно подписать подходящим способом.

## Проверки

Добавлены XCTest полного сброса после отключения и отказа восстановления при
ошибке удаления ключа. Они используют отдельные временные каталоги и настройки.
На Windows Xcode и iOS XCTest недоступны. Успешное выполнение workflow и
проверка восстановления на iPhone требуются перед признанием исправления
проверенным на устройстве.
